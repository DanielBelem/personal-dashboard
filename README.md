# Personal Dashboard

Personal project currently in development.

The goal is to build a simple personal dashboard where I can manage:

- Weekly class schedule
- Savings goals and progress
- Savings movements
- Personal expenses and transactions
- Financial summaries

## Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- Supabase

## Status

Currently working on the core features and database integration.

So far:
- Authentication with login/logout
- Weekly schedule connected to Supabase
- Savings goals, Saving movements, Progress tracking - being implemented

More features and UI improvements are still in progress.
